## Changes Applied

### 1. R29 Amendment — OU Parameter-Calibrated Dynamic Entry/Exit Thresholds
- **File:** `/workspace/group/MEMORY.md`
- **Risk:** low
- **Source:** arXiv:2604.02035 (April 2026) — RL for Speculative Trading under Exploratory Framework. Zhao, Tse, Zheng.
- **Summary:** Current R29 design uses fixed ±2σ z-score entry for all pairs. This paper shows via RL optimal stopping theory that entry threshold should be calibrated to OU parameters: fast-reverting pairs (half-life < 3 days) need ±1.5×σ_eq; medium (3-7d) need ±2.0×σ_eq; slow (>7d) need ±2.5×σ_eq. Natural spread unit is σ_eq = σ/√(2θ), not raw rolling σ. OU MLE runs in ~0.5ms on the same 60-day window used for cointegration testing — zero extra data cost.

### 2. R31 Implementation Warning — Never Anonymize Transcripts Before FinBERT
- **File:** `/workspace/group/MEMORY.md`
- **Risk:** low
- **Source:** arXiv:2511.15364 (Nov 2025) — Anonymization and Information Loss. Wu, Yang, Ying.
- **Summary:** Anonymizing earnings call transcripts (stripping company names, product names, numbers) destroys MORE signal than look-ahead bias. EDGAR transcripts are public — there is no privacy reason to anonymize. Critical implementation warning for R31: use raw transcripts with FinBERT; do NOT preprocess away named entities or numerical data.

### 3. R35 Amendment — Markov Clustered Efficient Frontier as 3rd Regime Signal
- **File:** `/workspace/group/MEMORY.md`
- **Risk:** low
- **Source:** arXiv:2604.03946 (April 2026) — Markov Process of Clustered EF Coefficients. Alexander et al.
- **Summary:** New portfolio-level regime detection using efficient frontier coefficient clustering. Detects when the Sharpe/correlation structure of the strategy mix degrades — more directly relevant to multi-strategy portfolio than return-distribution HMM. Has reproducible Python code. Added to R35 concept as primary regime layer, alongside Wasserstein HMM and skewness dispersion.
