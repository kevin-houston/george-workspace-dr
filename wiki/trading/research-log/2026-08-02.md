### New content added

**New page**: `paper-trading/dynamic-strategy-allocation.md` — covers two complementary
traditions for adaptive multi-strategy capital allocation:

1. **Online Portfolio Selection (OPS)**: `universal-portfolios` (Marigold, GitHub, 858★,
   `pip install universal-portfolios`) implements 20+ sequential regret-minimization
   algorithms (Cover's Universal Portfolio, OLMAR, CRP, Anticor, PAMR, CORN, RMR, etc.).
   Adaptation for our use case: feed it a DataFrame of daily NAV series per strategy sleeve
   (built from `strategy_accounts.json`) instead of per-asset prices — OPS algorithms are
   asset-agnostic and treat each sleeve's equity curve as an "instrument." Code example
   included (`OLMAR(window=5, eps=10).run(nav_df)`).
2. **Bandit-based strategy selection**: "Bandit Networks" paper (ADTS/CADTS, *Computational
   Economics* 2025, DOI 10.1007/s10614-025-11090-0 — Springer-paywalled, only abstract-level
   detail reachable this pass) frames each *strategy* (not each asset) as a bandit arm —
   directly fits George's setup of 7 well-defined sleeves. ADTS = Adaptive Discounted
   Thompson Sampling (discount factor keeps the posterior tracking recent performance, which
   matters given H437/H435/H436's finding of 2024-2026 OOS Sharpe compression vs. historical
   backtests). CADTS extends to selecting/weighting a *subset* of arms per period, matching
   our concurrent-sleeve setup. PRBO (arXiv:2208.02901, code at
   github.com/HarmoniaLeo/PRZI-Bayesian-Optimisation) adds an outer "bandit-over-bandit" loop
   for adapting the discount factor itself to regime shifts — composable with the existing
   VIX/200MA regime gates (H249/H286/H301/H362).
