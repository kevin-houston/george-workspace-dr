## Qlib deep dive (Session 1 priority — now complete)

Expanded `wiki/trading/tools/qlib.md` from a 52-line placeholder to a 250-line comprehensive reference.

### Key findings

**Performance benchmark**: Qlib's data layer is 20–25× faster than HDF5/MySQL/MongoDB on standard quant tasks. With full caching: 7.4s vs 184s for HDF5. The 3-tier cache (MemCache → ExpressionCache → DatasetCache) is the core differentiator.

**Model zoo — 20+ models**: Two tiers matter for us:
- **Gradient boosting (LightGBM, XGBoost, DoubleEnsemble)**: Best on Alpha158 tabular features. DoubleEnsemble leads with IC 0.0521, Info Ratio 1.34, annualized return 11.58%
- **Deep learning (HIST, IGMTF, TRA, TCTS)**: Better on Alpha360 raw OHLCV. HIST leads with Info Ratio 1.37, annualized return 9.87%

**Nested Decision Execution Framework**: The most sophisticated feature — daily alpha model drives intraday executor. Eliminates need for a separate execution layer. Supports TWAP/VWAP slicing out of the box.

**RD-Agent integration**: LLM-driven autonomous factor discovery. With `$OPENAI_API_KEY` available, we could run `rdagent fin_factor` to automatically generate novel alpha factors for the US market. ~30% success rate on ML Engineering benchmark. Three modes: `fin_factor` (factor mining), `fin_model` (model optimization), `fin_joint` (co-optimization).

### Assessment for project

- **Don't use for classical strategies** — overkill; current yfinance+pandas approach is better for H-series
- **Strong candidate for Phase 2 ML extension**: After classical momentum, use Qlib Alpha158+LightGBM or Alpha360+HIST to generate ML alpha factors
- **RD-Agent** is an interesting one-time experiment: run `rdagent fin_factor` on NASDAQ-100 to see what factors it discovers autonomously
- **Live trading gap**: No Alpaca connector built in — need a bridge from signal output to Alpaca order submission
- **Setup cost**: ~500MB of US daily data, one-time download; then fast via caching

- **Decision**: Stay on Alpaca for equity backtesting; upgrade to Polygon paid when options strategies begin

### yfinance status (important update)

yfinance is in worse shape than originally documented:
- September 2025: global data cutoff — all tickers returned data only through Sep 28, 2025 for weeks
- February 2025: Yahoo API change broke most versions
- 109 open GitHub issues as of April 2026
- Not thread-safe, breaks under rate limiting, unofficial scraping only

**Migration plan confirmed**: When yfinance next breaks, switch to **Tiingo** (free tier: 50 symbols/hour, 30+ years EOD history, official API, `tiingo` Python client). Drop-in replacement with same response fields.

### Tiingo — key discovery

Best-kept secret in free data:
- Free tier: 30+ years of EOD history (vs yfinance's ~7yr)
- Official supported API (not scraping)
- Clean Python client: `pip install tiingo[pandas]`
- Adjusted prices (adjClose) with explicit split/dividend factors
- 50 symbols/hour free limit — sufficient for batch backtest data collection
