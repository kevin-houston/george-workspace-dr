## New page: Momentum Strategies

`wiki/trading/algorithms/momentum-strategies.md` — 250+ lines

### What was written

Complete practitioner guide to momentum strategies with an emphasis on what the H001–H151 backtesting program actually found. Covers:

**Strategy taxonomy**
- Time-series momentum (TSMOM) — Moskowitz, Ooi & Pedersen (2012): 12-month lookback optimal across 58 instruments
- Cross-sectional momentum — Jegadeesh & Titman (1993): rank-based long/short
- ETF rotation (dual momentum) — Gary Antonacci (2014): TSMOM filter + cross-sectional ranking combined

**H-series findings distilled (7 key insights)**

1. **Rank ensemble beats single lookback** — rank(3m) + rank(6m) + rank(12m) + rank(inv_vol) confirmed H119; each lookback captures a different cycle
2. **TSMOM threshold matters** — optimal thresholds differ by asset type:
   - Sectors (H026): 12m lookback, +5% threshold — sector trends last quarters
   - Broad equities (H041a): 3m lookback, +0.5% threshold — equity corrections are fast
   - Bonds (H045): 3m lookback, +1% threshold — rate cycles resolve in months
3. **Top-1 concentration is optimal for monthly rotation** — holding #2 or #3 is portfolio dilution; signal quality decays below rank-1 for sectors and equities (confirmed H083, H096, H106, H135, H138); exception: H045 bonds hold top-2
4. **Universe expansion always helps** — each new ETF that passes dual-window test adds alpha; expansion from 11 to 25 assets roughly 17× the cumulative return
5. **Volatility targeting adds modest value** — except on single-leg portfolios where renorm neutralizes it (H148 discovery)
6. **Concentration in single best strategy beats diversification** — H026 going from 7% → 100% of portfolio improved performance monotonically (H089 → H149); other strategies were adding noise
7. **What doesn't work** — comprehensive table: longer lookbacks, 1m reversal penalty, dual TSMOM filters on H026, removing commodity ETFs, vol-targeting bonds, top-2/3 selection

Also includes production-equivalent Python code for the monthly rotation algorithm.

## New page: ETF Pairs Trading

`wiki/trading/algorithms/pairs-trading.md` — 280+ lines

### What was written

**Cointegration testing**
- Engle-Granger (two-asset, simpler) vs Johansen (3+ assets, more rigorous)
- Working Python code for both: `statsmodels.tsa.stattools.coint()` and `coint_johansen()`
- p < 0.05 = cointegrated; always test sub-periods for stability

**Known cointegrated ETF pairs**
Full table of 8 pairs: GDX/SIL, XLE/OIH, XLK/QQQ, EWA/EWC, TLT/IEF, SPY/IVV, XLF/KRE, GLD/IAU — with economic rationale and caveats

**Hedge ratio estimation (3 methods)**
1. Static OLS — simple, degrades over years (TLT/IEI slope dropped 1.38→0.9 over 2011–2016)
2. Rolling OLS — better, still noisy; use 252-day window minimum
3. Kalman filter (recommended for > 6-month holds) — working `pykalman` code

**Z-score signals**
- Entry ±2σ, exit ±0.5σ, stop-loss ±4σ (standard Gatev et al. thresholds)
- Optimized: entry ~1.4σ reduces whipsaw; exit ~0.3σ locks profits earlier

**Half-life of mean reversion**
- OU process formula: `half_life = ln(2) / (-θ)` where θ from AR(1) on spread
- Set lookback window = 2–4× half-life

**Walk-forward backtesting** — code template using 12m train / 3m test rolling windows

**Failure modes**
- Cointegration breakdown (GLD/GDX 2008, XLE/OIH 2020)
- Look-ahead bias in hedge ratio (most common error)
- Transaction costs eliminating near-arbitrage edge
- Sector reconstitution changing ETF composition
