### P1-P6 Minimum Reporting Protocol
- Two-group structure: Group A (evidence-source confounds: P1 Temporal Integrity, P2 Dynamic Universe, P3 Counterfactual Robustness) and Group B (evidence-to-decision mapping: P4 ECE calibration, P5 full friction including token API costs, P6 disaggregation)
- Key addition: P5 requires inference latency and token API costs — not modeled by any of the 5 audited systems

### System Audit Evidence (concrete numbers)
- TradingAgents: gross Sharpe 0.43 → net 0.22 after friction; $102.3K vs $104.8K buy-and-hold
- QuantAgent: gross -0.96 → net -1.15; $77.9K vs $104.8K buy-and-hold
- 35/40 friction cells unmodeled across 5 systems (commission only consistent)
- Both systems passed their own internal validation — key lesson: internal validation ≠ deployment evidence

### 6-Stage Modular Architecture
- LLMs as auditable upstream information extractors, not decision authorities
- Stages: Information Extraction → Feature Construction → Signal Synthesis → Probability Calibration → Sizing/Risk → Execution/Audit
- Note added: H163/H174 already satisfy this — FinBERT feeds into separate scoring/sizing layer

### Five Biases Framework (Kong et al. arXiv:2602.14233)
- Look-ahead, survivorship, narrative, objective, cost bias
- No single bias discussed in >28% of 164 reviewed papers
- Mapped to George's existing mitigations (`.shift(1)`, score gates, OOS Sharpe + MaxDD dual gate)

### Look-Ahead-Bench + FINSABER
- Look-Ahead-Bench: alpha decay as bias metric; standard LLMs (Llama 3.1, DeepSeek 3.2) show significant bias; PiT models generalize better
- FINSABER: LLM strategies overly conservative in bull markets, overly aggressive in bear markets; 20-year result reverses 2-year claims
