## New content: LLM embeddings vs price for stock clustering (EMH test)

New page `sources/llm-embeddings-vs-price-stock-clustering-2025.md` — Wang, Johnson, Hybinette & Balch, arXiv:2509.01590. Direct empirical EMH test: cluster stocks three ways (K-means on price correlation, GICS sectors, K-means on LLM embeddings of news headlines) and score each clustering by out-of-sample return-prediction RMSE. Price-based clustering wins by ~15% RMSE over both alternatives (15.9% vs GICS, 14.7% vs LLM embeddings) — a clean result *for* semi-strong EMH and directly relevant to the pairs-trading LLM-semantic-selection direction (H316 Moira / arXiv:2604.19476) already flagged as active in `algorithms/pairs-trading.md`.

Cross-linked into `algorithms/pairs-trading.md`'s existing arXiv:2604.19476 write-up: this paper is a caution, not a contradiction — 2604.19476's winning design already uses price/text co-occurrence to build the *candidate* graph and only uses the LLM to *filter* (remove economically implausible edges), which is consistent with price carrying most of the standalone signal. Added an explicit design note: any future H316/H319 implementation should use LLM text similarity as a filter on a price-derived candidate list, not as a standalone clustering signal — closes off one naive implementation path (embed-and-cluster-on-text-alone) before it gets proposed as a hypothesis.
