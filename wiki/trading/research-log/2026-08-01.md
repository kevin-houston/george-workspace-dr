Tonight, `WebFetch` on the raw PDF URL again failed (returned unparsed PDF stream data), but following the documented CLAUDE.local.md fallback — `curl -sL "URL" -o sources/pead-llm-enhancement-2025.pdf` then `Read` the local file directly — successfully extracted the full 13-page paper.

Key findings extracted:
- Compares BART vs FinBERT vs LLaMA-3.2-3B for PEAD prediction on **10-Q MD&A text** (2,628 NYSE firms, 2010-2024) — a different text source than our own H163/H174 pipeline (8-K Item 2.02).
- FinBERT wins classification accuracy (57.6%/58.3%); BART wins raw top-decile 60-day BHAR (3.29%/-3.18%) but the BART-over-FinBERT edge is **not statistically significant at the portfolio level** (N=16 quarters, Wilcoxon p=0.20-0.26) despite being significant stock-level (N=200+, p<0.03) — same stock-level-vs-portfolio-level significance gap this wiki has flagged before on outsized headline results.
- **3-day-return text-injection technique** (prepend `"The three-day stock return for this period was X.XX%."` to the MD&A text before scoring) improves accuracy and BHAR for all 3 models, statistically significant at both stock and portfolio level (p<0.05) — the paper's most robust finding.
- Discloses a 10-Q filing-lag limitation: 49.5% of firms file their 10-Q more than 2 days after the earnings release, undermining the same-day-availability assumption baked into the model — a look-ahead-adjacent caveat for any future 10-Q-based signal.

**Relevance to our pipeline**: the 3-day-injection technique is a genuinely new implementation angle distinct from H317 (NOT CONFIRMED) — H317 added EPS surprise + pre-momentum as hard filter thresholds, which cut n below the 20-event gate. This paper's technique instead folds the return into the FinBERT input as continuous text, without touching the H174 filter thresholds or reducing n. Flagged as a design candidate in the new wiki page; staged as a dream-cycle proposal below.
