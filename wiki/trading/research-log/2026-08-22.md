## Edit: backtesting/walk-forward-cpcv.md — Python Libraries section

Added `purgedcv` (github.com/eslazarev/purged-cross-validation, `pip install
purgedcv`, MIT license, PyPI + conda-forge) as a new library option:
sklearn-compatible purge/embargo/CPCV splitters *plus* `probabilistic_sharpe_ratio()`,
`deflated_sharpe_ratio()`, and PBO metric functions in one package — the
author positions it explicitly as filling the gap left by mlfinlab going
proprietary. Ships a JOSS paper with empirical validation results.

**Correction to the existing mlfinlab entry**: the page previously described
mlfinlab as "production-ready, integrates DSR" with a bare `pip install
mlfinlab` and no licensing caveat. Verified against the project's own
`LICENSE.txt`/`license.rst` on GitHub — mlfinlab is **all rights reserved**,
not open source, and requires a paid commercial license from Hudson & Thames
for commercial use. (One low-quality aggregator source claimed it was "free
and open source" — rejected in favor of the authoritative repo files.)

Also spot-checked mlfinlab's public `combinatorial.py` source: the
`CombinatorialPurgedKFoldCV`/`StackedCombinatorialPurgedKFold` split methods
are reduced to `pass`-only stubs, and no PBO computation is evident in that
file. Logged as an open question, not a confirmed claim — unclear whether
this reflects the full public package or is gated behind the paid tier.
Updated the DSR section's "use mlfinlab's exact implementation" line to point
to `purgedcv` instead, with the same caveat.

One lead did not pan out: an SSRN paper directly on-topic (look-ahead bias
audit framework for alpha factor models, Igor Merlini) returned HTTP 403 on
