Entertainment with numeric slope ranges rather than qualitative labels).

## What changed

`prediction-markets/superforecasting-methods.md`:
- Universal horizon effect table: μ(τ) rises 0.99 (0-1h) → 1.32 (1mo+), explaining 30.2% of
  calibration variance alone.
- Full 6-domain slope table replacing the old 4-domain one. Notable addition: **Weather is the
  only domain that goes the other direction** — short-horizon *overconfidence* (slope 0.69-0.97
  within 48h) rather than underconfidence, meaning the correct trade there is to fade extremes,
  not bid favorites like every other domain.
- Sports slope range corrected/expanded: near-calibrated short-term (0.90-1.10) but a sharp jump
  to 1.74 at 1mo+ horizons — the earlier page had sports as uniformly "well-calibrated, small edge,"
  which was only true for short-horizon markets.
- Kalshi-vs-Polymarket large-trade political scale effect quantified with bootstrap CIs: +0.53
  (Kalshi, robust to both market- and event-clustering) vs. +0.28 (Polymarket, not robust) — this
  was previously stated as "0.53 vs 0.11" without CIs; the CI detail matters because it tells us
  the Polymarket number isn't just smaller, it's statistically indistinguishable from zero once
  clustering is accounted for.
- Replaced the old ad-hoc `political_bias_adjustment()` additive-compression Python function with
  a `recalibrate_price()` implementation of the paper's actual logistic formula, plus a coarse
  slope-lookup table by domain × horizon bucket (flagged in-code as an approximation of the paper's
  full 216-cell supplementary matrix, which should be pulled directly for production use).
- Verified the new Python runs correctly (tested `recalibrate_price(0.70, "politics", "1w-1mo")`
  → 0.774, in the same range as the worked example in the paper).
