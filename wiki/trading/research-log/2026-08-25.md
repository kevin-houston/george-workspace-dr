## New content: Homerun (braedonsaunders/homerun)

Found via web research into 2026 open-source Kalshi/Polymarket backtesting
tooling. Verified via GitHub API directly (not just search snippets): 175
stars, AGPL-3.0, created 2026-02-03, pushed as recently as 2026-08-21 (active).
Same author has a separate, independently legitimate project (`codeflow`,
trending on trendshift.io) — no hallusquatting/scam signal on the account.

Confirmed not already in the wiki (`grep -ril homerun wiki/` returned nothing)
before writing.

Key findings added to `backtesting-frameworks.md`'s "Agent-driven trading
frameworks" section:
- **Architecture**: full-stack (FastAPI+Postgres+Redis backend, React/TS
  frontend, 16 background workers) — a materially bigger scope than the other
  three tools already documented on this page (PolyBot, polymarket-arbitrage,
  the two quant backtesters), which are CLI scripts or single-purpose engines.
- **25+ built-in strategies** spanning arbitrage (cross-platform Polymarket↔
  Kalshi, YES+NO mispricing, negRisk bundle mispricing, settlement-lag plays),
  microstructure (flash-crash reversion, VPIN toxicity detection), alt-data
  (LLM news scoring, weather forecasting, crypto 5m-4h binaries), social
  (whale-wallet mirroring, 27-point insider-anomaly scoring), and stat-arb/MM.
- **Backtest engine is the standout**: persists real Polymarket L2 order-book
  snapshots (25 levels/side, 0.5s sampling) rather than a flat spread proxy;
  fill probability from a Cox proportional-hazards survival model with
  queue-depth/spread/intensity/time-to-resolution/side-imbalance/volatility/
  latency covariates; explicitly decomposes observed depth loss into
  fills-vs-cancels (different adverse-selection implications); latency
  injected from rolling p50/p95/p99 across nine real pipeline stages; shadow-
  mode gives pessimistic/realistic/optimistic fill triangulation against live
  PnL. This is more rigorous than every other fill model previously logged in
  this section (Quentin-Piot's 2-cent flat-spread ask/bid convention was the
  prior best-documented approach).
- Working async `BaseStrategy`/`BaseDataSource` SDK code examples included.
- **License flagged explicitly**: AGPL-3.0 is copyleft — fine to read/adapt
  ideas locally, but redistributing a modified network service built on it
  would require releasing under AGPL too. Not a blocker for this project's use
  case (local research/backtesting reference), but noted so a future session
  doesn't skip the caveat.
- Updated the page's "Assessment vs. current stack" summary to add Homerun's
  fill-model idea as a concrete future-adoption candidate for H185 (Kalshi
  nowcasting) or the `market-making.md` strategy class, if either ever needs
  execution-quality backtesting beyond the current implicit mid-price-fill
  assumption.
