# Research Log — 2026-06-28

## Wiki Expansion

**Target**: `prediction-markets/ai-model-benchmarks.md` — thinnest meaningful page (132 lines, single study).

**Expanded to 226 lines** with three new 2026 papers:

1. **PolyBench (arXiv:2604.14199)** — 7 LLMs on live Polymarket (36,165 predictions, Feb 2026). Every model negative expected return. Confirms raw LLM calibration is near-random; structured data injection is the differentiator. Already in algorithmic-strategies.md but missing from benchmarks page.

2. **PolySwarm (arXiv:2604.03888)** — 50-agent LLM swarm for Polymarket/Kalshi trading. KL/JS divergence aggregation, latency arb module, quarter-Kelly sizing. Relevant to H185 Phase 2 upgrade: replace single-model with swarm consensus (10 personas ≈ $0.50/run at GPT-4o-mini).

3. **PredictionMarketBench (arXiv:2602.00133, GitHub: Oddpool/PredictionMarketBench)** — Deterministic Kalshi LOB replay backtester. Key result: Bollinger Bands (post-only maker) +1.67% vs GPT-4.1-nano -2.77%. Fee management dominates at this scale. Practical integration path for testing H185 before live.

**New synthesis table** added: 5-dimension assessment (raw calibration / agent infra / fee management / market selection / swarm aggregation) across all 3 studies.
