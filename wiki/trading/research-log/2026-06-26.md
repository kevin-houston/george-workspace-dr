### Key takeaways

- **arXiv:2602.07048**: Granger causality + LLM semantic filter raises Kalshi win rate from 51.4% → 54.5% and cuts average losing trade from $649 → $347. The mechanism: LLM vetoes pairs where no plausible economic transmission mechanism exists, suppressing false positives from spurious statistical correlations. Not equity-applicable but directly builds on H185 infrastructure.

- **arXiv:2603.27539**: Introduces "Coordination Primacy Hypothesis" — agent coordination protocol matters more than model scale for trading quality. CBS (Coordination Breakeven Spread) metric tells you whether multi-agent overhead is worth it. 5 evaluation failures systematically identified (look-ahead, survivorship, overfitting, cost neglect, regime blindness) — these are already guarded against in the pipeline.

- **arXiv:2510.07920**: "Profit Mirage" — LLM agent backtests evaporate post-training-cutoff because models memorize historical outcomes. FactFin uses counterfactual perturbations to force causal learning. Key implication: always use post-training-cutoff data for OOS evaluation of any LLM-based strategy (H163/H174 OOS window is already 2023-2026, partially post-cutoff).
