### H436 NOT CONFIRMED — Relative Strength vs SPY on H026 ETF Universe

**Fatal mathematical identity**: rank(x_i − c) = rank(x_i) for constant c. Subtracting common SPY return from each ETF's 12m return does not change the cross-sectional ranking. All 6 variants produce identical rankings to raw 12m momentum or the H026 canonical signal. Not worth implementing in live code.

**H026 canonical OOS**: 0.509 (Vars A/B/C) and 0.707 (Vars D/E).

### H435 NOT CONFIRMED — 52-Week High Proximity on H026 ETF Universe

**Method**: George & Hwang (2004) 52-week high anchoring; proximity = price / 52w_high.

**Look-ahead bias trap found**: Unshifted proximity signal gave implausible OOS Sharpe of 3.499. Corrected with `.shift(1)` → OOS 0.801 (Var A, pure proximity). All variants fail gate.

**Root cause**: Large ETFs near their 52-week high in bull markets = low cross-sectional variation. When everything is near its 52w high, the signal has no discriminating power. Proximity signal better than raw momentum on this universe but insufficient alone.

### Research Findings

**OpenBB Platform** (major new development):
- GitHub: github.com/OpenBB-finance/OpenBB (51k+ stars, MIT)
- `pip install openbb` — unified API over 100+ data providers
- Same call, swap provider: `obb.equity.price.historical("AAPL", provider="tiingo")`
- API server mode: `openbb api --host 127.0.0.1 --port 6900`
- MCP server: `pip install openbb-mcp` — direct Claude Code integration
- Latest release: v4.5, May 26, 2026
- Best practice: write against OpenBB schema, not individual providers

**IEX Cloud** — shut down retail stock data API in 2025. Dead. Do not use.

**yfinance** — "Effectively deprecated" per multiple sources. Feb 2025 Yahoo Finance redesign was a breaking change. Status: unstable, avoid for automated pipelines.

**Stooq** — free historical data, no key, no account, no documented rate limits.
- Access via `pandas_datareader.data.DataReader(ticker, "stooq", start, end)`
- Ticker format: `AAPL.US` for US stocks, `^SPX` for S&P 500
- US index data back to the 1900s
- Intraday (5-min, 60-min) limited to ~180 days

**Polygon free tier update**: Stock history capped at 1 year for free tier (previously more generous). Premium required for full history.

**Alpha Vantage**: Free tier = 25 req/day — hard ceiling. Rate limit when calling: 5 calls/min.

**Finnhub**: 60 calls/min on free tier. 20-minute delay on real-time quotes.

**Twelve Data**: 800 calls/day, 8/min free. 4-hour delay on historical data on free tier.
