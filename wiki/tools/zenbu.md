# zenbu.js

**Repo**: github.com/zenbu-labs/zenbu.js — MIT, 207 stars  
**Stack**: TypeScript (94%), Electron (Node.js in progress)  
**Install**: `npx create-zenbu-app`

JS framework for building desktop apps that are designed to be modified by users and AI agents. Source code is downloaded locally, hot-reloads on changes, and is git-tracked so user customizations survive updates. Plugin system for extending without touching core code.

**Status**: Alpha, not production-ready.
