# /visual-plan — Code-to-Storyboard Wireframing Skill

A Claude Code slash command skill that scans a codebase and automatically wireframes an entire user flow as a storyboard, making it easy to spot broken or missing states in a UI.

**Shared by:** @RoundtableSpace (0xMarioNawfal), June 26, 2026

## What it does

- Scans your code
- Identifies the user flow (pages, states, transitions)
- Outputs a storyboard of the full flow as wireframe panels
- Useful for spotting gaps, dead ends, or broken paths without manually tracing the UI

## Relevance

Potentially useful for any frontend/dashboard work — e.g. the paper trading EOD dashboard, here.now summary pages, or any UI Kevin builds. Acts as a visual audit tool rather than a code correctness tool.
