# Dograh

**Repo**: github.com/dograh-hq/dograh — open-source, self-hostable  
**Stack**: Python 55% (FastAPI), TypeScript/Next.js 41%; Docker  
**Install**: single `docker` command, running in under 3 minutes

Self-hostable voice agent platform — open-source rival to Vapi and Retell. Drag-and-drop workflow builder for inbound/outbound call agents and web-based voice interactions. Bring your own LLM, TTS, and STT components. Built-in telephony (Twilio, Vonage, Telnyx). QA node for prompt quality analysis.

**Use cases**: lead qualification, customer support, appointment scheduling, human handoff.
