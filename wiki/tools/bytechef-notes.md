# ByteChef

Open-source platform that unifies AI agent orchestration and workflow automation — visual drag-and-drop workflow builder with LLM/agent support.

- **Repo**: github.com/bytechefhq/bytechef
- **Stars**: ~839 (June 2026)
- **Language**: Java + TypeScript
- **Self-hosted**: yes
- **License**: open-source (check repo for exact license)
- **Homepage**: bytechef.io

## What it does

Visual workflow builder for AI agent orchestration. Positioned as a self-hosted alternative to n8n / Zapier / Workato with native AI agent and LLM integration. MCP support is listed as a topic.

## Key features (from repo topics)

- Visual low-code/no-code workflow builder
- AI agent orchestration (LLM-native)
- MCP integration
- API/integration hub (embedded iPaaS)
- Self-hosted
