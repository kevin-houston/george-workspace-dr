Known gap: point-in-time data. yfinance and most free sources aren't survivorship-bias-free — they reflect today's index membership, not what it was on a historical date. This has blocked or flagged three hypotheses (H158 deferred, H167 blocked, H277 confirmed-but-not-production). Documented with a full provider comparison (fja05680/sp500, Norgate, Sharadar, WRDS CRSP, Bloomberg) in the wiki — free sources are fine for large-cap/low-turnover universes, but a paid vendor is the honest fix for small/mid-cap or ML multi-factor work.

massive new — added 2026-07-30

A market-data gateway to Massive.com's REST API, wired to $MASSIVE_KEY. Three-tool design:

  • search_endpoints — natural-language search over the API catalog (stocks, options, crypto, forex, futures, indices, economy, alternative, reference data) to find the right path before calling it.
  • call_api — fetches a discovered endpoint path, with an optional store_as to cache the result as an in-memory table.
  • query_data — runs SQL (including full-text search via FTS5 with MATCH/rank/ snippet()) against stored tables, plus a built-in quant function library: Black-Scholes greeks (bs_price, bs_delta, bs_gamma, bs_vega, bs_theta, bs_rho), returns (simple_return, log_return, cumulative_return), technicals (sma, ema), and risk-adjusted ratios (sharpe_ratio, sortino_ratio).
Not verified working yet. As of this write-up, search_endpoints reliably surfaces the built-in quant functions but returns "no matching endpoints found" for essentially every market-data query tried (stocks, options, economy, reference, crypto, forex, futures, indices — with and without a market filter). Calling a known Polygon-style path directly (/v2/aggs/ticker/AAPL/range/1/day/...) also failed with a "path not in allowlist" error. The endpoint catalog itself looks unpopulated or misconfigured right now — the SQL/quant-function layer is confirmed present, but no actual market data has been successfully pulled through this server yet. Flagging for follow-up rather than treating it as a working data source.
