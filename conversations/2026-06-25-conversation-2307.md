**SSRN 2715517 — "A Practical Guide to Quantitative Volatility Trading" (Daniel Bloch, 2016)**

This is a 900-page quantitative finance textbook, not a backtest paper. Heavy theory. The tradeable content lives in Part II / Chapter 7.

---

**Core ideas:**

**1. Variance swaps (§7.1)**
Forward contracts on realized annualized variance — payoff = (realized var − strike) × notional. Key insight: the fair strike equals the expected realized variance, which can be model-independently replicated using a weighted strip of OTM options (the Carr-Madan log-contract decomposition). No delta hedging needed. Clean vehicle for vol views.

**2. Dispersion trading (§7.6)**
The main practical strategy. Sell index vol (SPX straddles/strangles), buy individual component vol. Exploits a persistent **implied correlation premium** — index options are structurally overpriced relative to single-stock options because they embed a correlation risk premium (correlations spike in crashes, so index put sellers demand extra).

Signal for timing entry:
- Implied correlation near historical highs
- Index implied vol > realized vol (the familiar RV < IV gap)
- Metric: `Mρ = σ²_index / (weighted avg component vol)²` → if > 1, index is expensive, sell it

Practical setup: short ATM straddle on SPX, long straddles on 30-40% of constituents (by market cap / liquidity / highest IV). Vega-neutral weighting preferred.

**3. MixVol model (§6.2)**
A parametric arbitrage-free implied vol surface model for fitting and risk-managing the whole trade.

---

**Key caveats:**
- Deng (2008): dispersion was very profitable through 2000, then largely arbitraged away as options markets became more efficient. Marshall (2008) found the correlation risk premium persists but is smaller.
- Requires delta-hedging the component options continuously — execution-heavy.
- Single-stock variance swaps are illiquid except for large caps.
